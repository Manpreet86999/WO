# Body OS 4.5.5

## Critical startup repair

- Fixed the startup failure that could show **“Couldn’t load Body OS”** after an update.
- Older encrypted integration credentials are now isolated safely if their original Windows encryption key is unavailable.
- Training records, plans, reports, backups, and local data continue to load normally.
- Only the affected integration is reset to **Not connected**. Re-enter its credential in Settings only if you still want to use that service.

## Included features

- Retains 4.5.4 flexible-week mode, multi-exercise tracker entry, redesigned Settings, and Google Fit readiness import.
