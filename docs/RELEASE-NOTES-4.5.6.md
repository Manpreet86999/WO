# Body OS 4.5.6

## Reliable AI reports

- A finished workout is saved before AI or email work begins.
- **Save & send AI report** now sends only after AI analysis is valid and Gmail delivery succeeds.
- Failed AI or email delivery is kept as a durable pending report. The Dashboard offers **Retry reports** when Body OS opens again.
- Report emails include a visible, point-by-point **AI recommendations** section.
- If the optional report screenshot cannot be created, delivery falls back to the styled HTML report instead of failing.

## Clearer connections

- Google OAuth credential JSON can be uploaded in Settings and is shared by Google Fit and Google Drive.
- Google Fit and Drive remain separately authorized, so either service can be disconnected safely.
- Context help explains the exact localhost redirect URLs for Google, Gmail App Password setup, and accepted AI model formats.
- AI settings now use a small stable suggestion list and allow a typed model ID, verified with **Test AI**.

## Important

For Gmail, enable 2-Step Verification and create a Gmail App Password. For reports, configure and test both AI and email in Settings before logging a workout.
