# Body OS 4.5.4

## Flexible training mode

- Added the **Preplanned Week** setting, enabled by default.
- Turn it off to start a flexible Monday–Sunday training week from today, this Monday, or next Monday.
- Complete days in order with a full workout or a Rest day.
- Build workouts from target muscles, Library exercises, or new exercises saved directly to Library.
- At week end, name the completed week and save it as a reusable one-week Program.
- Add several exercises before the flexible tracker opens, then log their flashcards in order.
- When flexible mode is active, Program weeks and Library plans cannot be activated. Only the current flexible week can run.

## Existing training

- Imported plans and the existing planned-week workflow are unchanged when Preplanned Week is enabled.
- Flexible workout records use the same Tracker, analytics, reports, backup, and sync data as planned workouts.

## Daily readiness and settings

- Google Fit can now prefill available sleep duration, average heart rate, and steps directly into the readiness check-in. Personal ratings still require the user&apos;s own answer.
- Removed unused Google Fit nutrition permissions.
- Rebuilt Settings into Profile, Security, Integrations, Backup & Data, Updates, and Help tabs.
- Profile now separates the user&apos;s account email from report-email delivery settings.
