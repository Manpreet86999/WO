# Body OS 4.5.1 — Update reliability hotfix

- Restores the stable installer identity used by earlier Workout OS/Body OS releases.
- Existing installations are now recognised as upgrades and retain their existing install location.
- Keeps the single-file update design: users download only `BodyOS-Setup.exe`; requirements are embedded and checked automatically.
- Preserves the update safety backup, dependency check, server restart, and post-update release-notes dialog.

This release replaces 4.5.0. Publish it with the GitHub tag `v4.5.1` and upload only `BodyOS-Setup.exe`.
